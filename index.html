Before you edit

Your changes are saved only in this browser on this computer. The original deck on the website does not change.

  • Another computer, or another browser on this computer, shows the original deck.
  • Clearing your browser data erases your changes.
  • In a private or incognito window, changes are lost when the window closes.
  • Pictures are shrunk to save space. A browser can usually hold a few dozen picture cards. The page warns you if it runs out of room.

Edit cards

Changes are saved only in this browser on this computer. They do not change the original deck for anyone else. Clearing browser data erases them.
